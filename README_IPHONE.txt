MAHALS FURNITURE BILLING – iPhone PWA

This package is the working Mahals Furniture billing app prepared for iPhone installation as a Progressive Web App (PWA).

IMPORTANT
- It must be opened from an HTTPS website to install on iPhone. Opening index.html directly from Files will not install the PWA.
- Your existing browser/localStorage data does not automatically sync between the PC copy and iPhone. The iPhone copy has its own local data unless a future cloud sync system is added.

INSTALL ON IPHONE
1. Put this folder on an HTTPS host (for example GitHub Pages, Netlify, or another HTTPS static host).
2. Open the website in Safari on the iPhone.
3. Tap Share -> Add to Home Screen -> Add.
4. Open “Mahals Billing” from the Home Screen.

FEATURES
- Customer/product add and edit
- Inventory
- GSTIN check-digit validation
- CGST/SGST for Gujarat
- IGST for other states
- Invoices, payments, reports and ledger
- Invoice template
- PDF/print sharing
- Offline caching after first load
